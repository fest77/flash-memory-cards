导入与提问设置

改动后，下次导入的笔记按新设置拆分；已导入的可以删掉重导。

AI 提炼设置（可选，需要你自己的 API）

不经过任何服务器，请求从本机直接发到你在上面填的地址。浏览器直连多数厂商 API 可能被跨域拦截（CORS）： 可以用本机 Ollama（启动前设 OLLAMA_ORIGINS=*），或改用电脑上的 tools/ai_cards.py 生成卡片 JSON，再用「导入 AI 卡片」。

数据只保存在本机浏览器里，不上传任何服务器。
换手机 / 清理浏览器前，记得用「备份」导出 json，再到新手机「恢复」。
手机浏览器菜单里选「添加到主屏幕」，可以像 App 一样打开。
